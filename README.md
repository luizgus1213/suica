# Suíça — Front-end HTML & CSS

Landing page responsiva dedicada às paisagens naturais da Suíça.

## Tecnologias

- HTML5
- CSS3
- CSS Grid e Flexbox
- Animações com `@keyframes`
- Animações de entrada com `animation-timeline: view()` em navegadores compatíveis
- Layout responsivo

## Como abrir

Clone ou baixe o repositório e abra `index.html` no navegador.

```bash
git clone URL_DO_REPOSITORIO
cd suica-frontend
```

Não é necessário instalar dependências.

## Estrutura

```text
suica-frontend/
├── index.html
├── style.css
└── README.md
```
